# Changelog - G.E.I. Agent

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-25

### Added
- **Virus Spread Simulation Layer**
  - 200-node dynamic cyber network topology
  - Four virus strain types (cyber-phage, data-worm, logic-bomb, trojan-fox)
  - Real-time infection propagation with distance-decay model
  - Visual indicators: pulsing nodes, connection highlighting, threat levels
  
- **AGI AI Defense Systems**
  - Neural network monitoring visualization
  - Threat detection console with live feed
  - Countermeasure deployment (scan & contain operations)
  - AGI AI toggle for active defense mode
  - Glitch/signal effect visualizations
  
- **Enhanced GEV Features**
  - All original God's Eye View features preserved and functional
  - Voice control integration (requires OpenAI key)
  - Cockpit mode with sensor switching
  - Scene director cinematic captures
  - Shareable scenes as URL links

### Changed
- Combined all GEV layers into unified application
- Added new virus simulation panel alongside globe view
- Integrated AGI AI effects overlay system
- Enhanced visual styles with cyberpunk aesthetic

### Fixed
- Initial release fixes for network topology calculations
- Infection spread algorithm stability improvements

### Security
- Implemented $5 session spend cap for OpenAI voice
- Rate limiting configuration per provider
- LAN sharing security considerations documented
