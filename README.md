# G.E.I. Agent - God's Eye View Enhanced

## 🦠 Computer Virus Spread Simulation with AGI AI Effects

G.E.I. Agent is an **enhanced version of God's Eye View** that combines the original satellite visualization capabilities with a powerful computer virus spread simulation and advanced AGI (Artificial General Intelligence) AI defense systems.

### ✨ Features

#### 🌍 **Original GEV Features**
- **Photorealistic 3D Globe** via Cesium (with free Cesium Ion token support)
- **Live Aircraft Tracking** - 11,000+ real-time aircraft with OpenSky data
- **Live Ship/Vessel Tracking** - Thousands of ships worldwide via AISStream
- **Satellite Tracking** - 838-object satellite catalog including ISS and Starlink
- **Earthquake Monitoring** - Global seismic activity from USGS
- **Weather Layers** - Wind, clouds, lightning, cyclones (NOAA data)
- **Public CCTV Feeds** - Live camera projections into 3D city space
- **Voice Control** - Hands-free navigation and queries (requires OpenAI key)
- **Cockpit Mode** - Ride inside tracked aircraft with sensor switching
- **Scene Director** - Capture cinematic camera tours

#### 🦠 **New Virus Spread Simulation**
- **Real-time Network Visualization** - 200-node cyber network topology
- **Four Active Virus Strains**:
  - `cyber-phage` - Fast-propagating malware
  - `data-worm` - Self-replicating data exfiltrator
  - `logic-bomb` - Conditional destructive payload
  - `trojan-fox` - Backdoor/remote access tool
- **Dynamic Infection Spread** - Network-based propagation model
- **Visual Effects**:
  - Pulsing infected nodes with red glow
  - Connection line highlighting during spread
  - Real-time infection level tracking (0-100%)
  - Threat level indicators: LOW → MEDIUM → HIGH

#### 🤖 **AGI AI Defense Systems**
- **Neural Network Monitoring** - Visualized neural network activity
- **Real-time Threat Detection** - Instant identification of new infections
- **Countermeasure Deployment**:
  - Scan & Contain operations
  - Neural defense field activation
  - Automated response protocols
- **AGI AI Console**:
  - Live threat analysis feed
  - Glitch/signal effect visualizations
  - Response system status
- **AI Control Panel**:
  - Full network scan initiation
  - Countermeasure deployment
  - System reset capabilities

### 🎮 Controls & Commands

#### Voice Commands (Requires OpenAI key)
```
"Take me to Tokyo and show me all aircraft"
"Switch to FLIR night vision mode"
"Orbit around the ISS"
"Turn on the weather layers"
"Track that plane"
"Enter cockpit view"
"Show me space missions"
"Switch to OSM basemap"
```

#### Keyboard Shortcuts
- `1` - `7`: Cycle through visual styles (Normal, NVG, FLIR, etc.)
- `H`: Toggle HUD overlay
- `D`: Toggle detection boxes
- `C`: Enter cockpit mode
- `` ` ``: Show/hide frame rate counter
- `Esc`: Exit current view

#### Virus Simulation Controls
- **"Accelerate Infection"**: Speed up virus spread
- **"Reset Network"**: Clear all infections and restart
- **"Scan & Contain"**: AGI AI active scan operation
- **"Deploy Countermeasures"**: Activate AI defense systems

### 📦 Installation

#### Method 1: Pinokio (One-Click)
1. Install [Pinokio](https://pinokio.computer/) v8.2+
2. Find "God's Eye View Enhanced" in the app store
3. Click **Install** then **Start**

#### Method 2: Terminal Installation
```bash
git clone https://github.com/[your-username]/gei-agent-virus-sim.git
cd gei-agent-virus-sim
npm ci
npm run doctor
npm run dev
```

Then open http://localhost:4173 in your browser.

### 🔑 API Keys (Optional but Recommended)

| Key | Purpose | Cost |
|-----|---------|------|
| **Cesium Ion** | 3D globe, terrain, Google Photorealistic 3D | Free tier available |
| **OpenAI** | Voice control & AI HUD summary | Metered (~$5 cap built-in) |
| **Google Maps** | Direct 3D tiles + place search | Free tier (1000 sessions/mo) |
| **AISStream** | Live ship tracking | Free signup |
| **NASA FIRMS** | Active fire detection | Free |

Add keys via the app's **POWER UP** panel.

### 📊 Data Sources

- **Aircraft**: OpenSky Network, ADS-B Exchange
- **Ships**: AISStream
- **Satellites**: CelesTrak TLE database
- **Earthquakes**: USGS (United States Geological Survey)
- **Weather**: NOAA GFS/ECMWF forecasts and nowCOAST observations
- **CCTV**: City of Austin, California Caltrans, London TfL, etc.
- **Radio**: Radio Browser API
- **Routing**: OSRM on FOSSGIS servers

### 🛡️ Security & Privacy

- All API keys stored locally (`.env` or Pinokio's `pinokio/ENVIRONMENT`)
- Server binds to `localhost` by default (not exposed to network)
- OpenAI key only sends short-lived session tokens to browser
- See [SECURITY.md](./SECURITY.md) for full threat model
