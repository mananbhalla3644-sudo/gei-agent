## 🚀 Quick Installation (3 Methods)

### Method 1: Pinokio (Easiest) ⭐ RECOMMENDED
```bash
# 1. Install Pinokio from: https://pinokio.computer/
# 2. Find "God's Eye View Enhanced" in Discover → Download from URL
# 3. Paste repo URL and click Install, then Start
```

### Method 2: Terminal
```bash
cd <this repository>
npm ci           # Install dependencies
npm run doctor   # Check system status
npm run dev      # Start development server
# Then open http://localhost:4173
```

### Method 3: Direct npx Run
```bash
npx -y gei-agent-virus-sim@latest start
```
